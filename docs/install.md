# Install

## From Community plugins

After Unique Word Tracker is accepted:

1. Open **Settings → Community plugins**
2. Turn Restricted mode off if it is still on
3. Browse and search for **Unique Word Tracker**
4. Install and enable it

## By hand

1. Download `main.js`, `manifest.json`, and `styles.css` from the latest release:
   https://github.com/ChrostnWo/unique-word-tracker/releases
2. Put those three files in:

   ```
   YourVault/.obsidian/plugins/unique-word-tracker/
   ```

3. Reload Obsidian
4. Enable **Unique Word Tracker** under Community plugins

The folder name must match the plugin id, `unique-word-tracker`.
